# 证据模板

## 数据流

```text
输入源：[file:line]，[可信/不可信]
路径：源 -> 校验[file:line] -> 转换[file:line] -> 汇[file:line]
调用者约束：
- [调用者 file:line]：[约束]
校验点：
- [条件 file:line]：[通过/失败/可绕过]，原因：[证据]
结论：[攻击者数据到达汇 / 被阻止 / 尚未确认]
```

## 攻击者控制

```text
输入向量：[HTTP/文件/IPC/参数等]
控制程度：[完全/部分/无]
限制：[长度、字符集、权限、状态]
可达性：[具体调用链]
证据：[file:line]
```

## 数学证明

```text
主张：[运算] 会导致 [异常]
变量与类型：[名称、位宽、符号]
约束：
1. [约束]，来源 [file:line]
2. [约束]，来源 [file:line]
推导：
1. ...
2. ...
N. 因此条件 [可能/不可能] 成立。
具体触发值：[值]，或“不适用/不可能”的证明。
```

## 影响

```text
机密性：[影响/无，证据]
完整性：[影响/无，证据]
可用性：[影响/无，资源比例、持续时间、恢复行为]
认证边界：[影响/无]
授权边界：[影响/无]
主要控制与纵深防御：[区分]
```

## PoC

```text
攻击输入 -> 校验 -> 转换 -> 危险操作 -> 可观察影响

```
